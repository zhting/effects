# 大雁塔 · 三维院落

西安大慈恩寺院落的简化三维模型，可环绕观察大雁塔、拆解塔身结构，并切换天气、光照与路径追踪静帧。
场景写在一个 HTML 文件里（内联 three.js r186、three-gpu-pathtracer 0.0.27、three-mesh-bvh 0.9.16），不需要构建，也不依赖 CDN。

## 目录

```
index.html              单文件场景：样式、脚本与三方库全部内联
audio/narration.mp3     固定讲解录音（narration_v2.mp3，约 4 分 19 秒，11 节）
```

## 操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 旋转视角 | 鼠标拖动 / 方向键 | 单指拖动 |
| 缩放 | 滚轮 / ＋ － | 双指捏合 |
| 复位 | Home 或「回到初始视角」 | 「回到初始视角」 |

- **拆解大雁塔**：塔基、一至七层、塔顶、塔刹逐层展开，点选构件或标签查看说明，「合拢复原」还原。
- **讲解演示**：固定播放 `audio/narration.mp3`，按录音中的段间停顿划分 11 节。镜头、章节进度与字幕均由录音播放位置驱动；支持试听、暂停、继续、跳节与重新播放，不切换系统语音。构建时会一并复制音频资源。
- **标注 / 环绕**：显示建筑标签；开启自动环绕镜头。
- **天气**：晴、多云、阴、雾、雨、雷雨、雪。
- **时间**：滑块调整一天中的时间（06:00–23:30），光照与夜景随之变化。
- **夜景**：一键切到当晚 20:30，并转到能看到月亮的视角。月相按 2026 年 10 月 22 日推算（盈凸月），月亮方位取当晚实际方位，高度与大小为便于观看的示意。
- **光追静帧**：镜头静止时用显卡做渐进式路径追踪，首次需约十几秒构建 BVH。

镜头始终围绕观察中心、保持在地面上方。院外的城市街区、道路与车辆为示意，不对应真实建筑。

## 技术栈

Three.js · three-gpu-pathtracer · three-mesh-bvh · WebGL2
